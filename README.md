# CoffeeGo
Призначення: мобільний додаток для мережі кав'ярень, який дозволяє клієнтам заздалегідь замовляти каву, оплачувати замовлення карткою або телефоном, накопичувати бонусні бали та отримувати сповіщення про готовність замовлення. хіхіхаха

Тип системи: Mobile + Backend/API + веб-кабінет для менеджера та баристи
